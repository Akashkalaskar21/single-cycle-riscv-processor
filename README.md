# 32-bit Single-Cycle RISC-V Processor

A 32-bit single-cycle RISC-V processor implemented using Verilog HDL and Xilinx Vivado 2025.2.

### Features

* ALU, register file, and control unit
* Instruction and data memory
* Immediate generation and branching
* Supports `ADD`, `SUB`, `AND`, `OR`, `ADDI`, `LW`, `SW`, and `BEQ`

### Tools

* Verilog HDL
* Xilinx Vivado 2025.2
* XSim Simulator
